# Root 工具与设备美化移植库

直接复制自同一工作区 `hyperos4/hyperhome/streamline`，其原始工具来自 `Hyperos4-Streamline`；本版移除依赖 SystemUI Hook 的导航栏页面与后端。保留其功能后端、规则、机型预设、关于手机视图与米兔素材，界面由宿主统一提供入口和样式；该目录构建 Android library，不生成第二个安装包。

宿主为 **澎湃工坊 / HyperCraft**（`io.github.dalong.hypercraft`）。Root 运行目录独立使用 `/data/adb/hypercraft`，通用启动入口为 `/data/adb/post-fs-data.d/hypercraft.sh`、`/data/adb/service.d/hypercraft.sh`，外部备份默认为 `/storage/emulated/0/HyperCraft`。不会读取或重放来源应用的 Root 配置；旧运行目录和旧应用数据保留。用户可通过已有备份导入功能自行迁移，不应在新旧应用同时开启同一项 Root 控制。

新安装的“我的设备美化”和独立米兔宠物开关默认关闭。充电控制与充电记录默认关闭，不启动采样守护。旧 Root 模块配置仅支持显式 `migrate` 导入，开机不会自动导入。宿主 Application 统一注册 libxposed 服务监听器，并将 bind/died 事件交给 `XpService.accept` / `XpService.clear`；库自身不再注册第二个监听器。宿主 API 102 Java 入口列表还应包含 `com.dalong.pengpaitool.xp.Entry`，设备美化需设置作用域。

Root 命令的标准输出和错误输出各保留最多 2 MiB；超出后继续排空管道并标记截断，避免输出撑大内存或阻塞子进程。

各常驻任务在访问硬件前取得独占锁，后台启动在新 session 内握手后返回，前台命令取消或退出只清理自身进程组。充电曲线每个活动会话最多约 8192 个历史点，达到上限后降采样，保留首末时间戳与区间电量、功率积分；完成会话最多保留 60 份。

应用冻结、卸载、恢复、导入和开机重放使用独立事务锁。修改包状态前先保存恢复记录，取消或命令回包丢失也能恢复；成功恢复需回读安装和启用状态。外部 APK 备份通过管道交给 PackageInstaller，避免系统服务直接读取私有备份路径。备份文件使用独占锁和原子替换。

系统开关首次启用必须读取并保存原始值，写入和恢复均需准确回读；失败保留恢复记录，无记录的关闭操作不修改系统。空字符串与缺失键分别恢复。开关界面、开机重放、导入和备份共用独立开关事务锁。Android mksh 会将未转义的 `|` 视为裁剪模式中的或运算符，所有字段裁剪统一使用字面量 `\|`；可选真机测试覆盖完整机型快照解析和重启标记清除。

系统更新屏蔽与反诈控制在首次启用时保存准确的 User 0 组件覆盖、权限及设置基线，重复启用不会覆盖原值；恢复失败保留基线供重试，接口不可读时拒绝写入。电池循环伪装统一在 init 挂载命名空间运行，只清理本库拥有的绑定；命名空间无法进入或存在外部绑定时拒绝操作。

`reporting.sh` 独立控制 User 0 的 `com.mobiletools.systemhelper` 与 `com.miui.guardprovider`。独占锁覆盖读取、持久记录、写入和回读；启用状态 0–4 精确恢复，缺失包、查询失败、部分失败和恢复中断不覆盖基线。卸载恢复失败时保留通用开机恢复入口，下一次开机仅重试恢复，不重放正常后台。域名屏蔽使用独立 `hosts_reporting` 规则组，双栈映射三个已知目的地，并回读 init 命名空间规则。此功能不新增常驻任务、定时器或抓包服务；不覆盖其他应用、其他用户、自带 DNS 或新增域名。

检测到来源应用的旧 Root 启动脚本、运行守护或绑定时，新后端会拒绝同时启动。用户明确停用后仅归档旧启动入口、停止旧守护并撤销可证明归属的旧绑定，保留旧 APK 与配置。旧绑定、强制停止或早期机型属性可能污染当前基线时，要求重启后再启用新后端。

本库不复制来源工程的签名、Gradle 缓存、构建产物或本机数据。`tests/` 在临时目录执行生产脚本和 ADB 桥解析；默认不连接手机或访问真实 Root 节点。

```sh
python3 -m unittest discover -s "streamline/tests" -v
bash "./gradlew" :streamline:testDebugUnitTest
```
