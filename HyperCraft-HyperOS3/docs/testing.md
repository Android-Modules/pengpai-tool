# 本版构建与验证

2026-11-10，版本 `0.3.0-hyperos3.1`（38），POCO F9 Ultra（songyuan / 26077PC53G），HyperOS `OS3.0.306.0.WGNMIXM`，Android 16/API 36。以本次结果替代源项目 HyperOS 4 的历史验证记录。

## 构建

JDK 21.0.2、Gradle Wrapper、SDK 37 编译。Debug / Release 构建通过；app 5 项、streamline 44 项 JUnit 全部通过。两模块 Release lint 无错误；app 2 条 Warning，streamline 80 条 Warning、4 条 Hint，主要为上游私有 API、旧接口和绘制建议，未通过全局屏蔽隐藏。

后端 Python 共 117 项：113 项通过，4 项可选环境测试跳过。测试在临时目录执行，不使用真实系统节点替身冒充真机结果。

## 页面与裁剪

五组、30 个工具页共 35 个目的地完成真机打开与图像渲染；WLAN 密码页不导出截图。机型与反诈页增加等待后复查，内容正常加载。反诈三项后端读取约 3 秒；修正探针对字符串等待参数的解析，避免将过早截图误判为页面卡住。首页保留原澎湃工坊卡片、配色与图标，仅显示五组工具。

本机另一个已安装服务占用 UiAutomation，原辅助功能断言探针会被拒绝连接；本次使用真实 Activity + PixelCopy 渲染检查，不把渲染成功等同于全部控件行为通过。实际系统读写由上表的独立 Root 探针验证。

设备美化的雾蓝白、银灰香槟两套主题均已在真实系统设置页面显示；测试后恢复雾蓝白并关闭美化，确认回到系统原生页面。

最终收尾探针 9/9 通过：备份同步、刷新率/CPU/OTA/循环/机型控制关闭、临时测试包不存在、两阶段开机入口存在。充电在线，控制与记录关闭，无充电守护。

打包检查确认无桌面原生库、native 初始化入口、桌面/智能助理/系统界面作用域。Java 入口只含设备美化 `Entry`，推荐作用域只有 `com.android.settings`。Release 不包含 instrumentation 或调试探针。

## 边界

充电控制保持关闭，真机只读检查充电、温度、电流与节点状态；充电策略变更、保护与恢复通过临时节点主机测试，未在本次手机上长时间运行温控策略。色彩选项、温度墙等按本机能力显示。未执行恢复出厂、真实系统更新、真实业务应用卸载、换卡激活、长期功耗或所有参数极值测试。

工作区原始日志、截图与 APK 保留在项目外的 `debug/hyperos3-fulltest-20261110` 及构建输出目录；不将私人手机数据加入源码。
